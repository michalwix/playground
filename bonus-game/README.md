# בונוס - משחק אותיות בעברית

משחק Scrabble-like בעברית (RTL) - MVP מלא ופונקציונלי.

## הפעלה

פשוט פתח את הקובץ `index.html` בדפדפן. אין צורך בהתקנות או בנייה - המשחק רץ ישירות מהקובץ.

## כללי המשחק

### מטרת המשחק
לצבור נקודות על ידי יצירת מילים תקניות בעברית על הלוח.

### מהלך תור
1. **בחירת אות**: לחץ על אות מהמגש (7 אותיות) כדי לבחור אותה
2. **הצבת אות**: לחץ על תא ריק בלוח כדי להציב את האות הנבחרת
3. **ביטול הצבה**: לחץ על אות שהוצבה בתור הנוכחי כדי להחזיר אותה למגש
4. **אישור מהלך**: לחץ על "אשר מהלך" כדי לאמת ולחשב נקודות

### כללי הצבה
- כל האותיות שהוצבו בתור חייבות להיות באותה שורה **או** באותה עמודה
- לא יכולים להיות רווחים בין האותיות הקיצוניות (כולל אותיות קיימות)
- מהלך ראשון: יכול להיות בכל מקום על הלוח
- מהלכים נוספים: חייבים לגעת באותיות קיימות (מעל/מתחת/מימין/משמאל)

### יצירת מילים
- **מילה ראשית**: לאורך כיוון ההצבה (אופקי או אנכי)
- **מילים צולבות**: בניצב לכל אות שהוצבה
- כל מילה חייבת להיות באורך של לפחות 2 אותיות
- כל המילים חייבות להיות במילון

### ניקוד
- כל אות יש לה ערך נקודות
- **DL** (Double Letter): מכפיל את ערך האות
- **TL** (Triple Letter): משלש את ערך האות
- **DW** (Double Word): מכפיל את כל המילה
- **TW** (Triple Word): משלש את כל המילה
- מכפילים מצטברים (DW + TW = x6)

### צ'ופרים (Rewards)
- **כוכב ⭐**: +20 נקודות לכל כוכב שדרכה עליו אות חדשה
- **קומבו**: +10 נקודות אם נוצרו 2+ מילים במהלך אחד

### משימות אקסטרה
3 משימות שניתן להשלים פעם אחת במשחק:
- **מילה ארוכה**: יצירת מילה באורך 6+ אותיות → +15 נקודות
- **שימוש ב-DW/TW**: שימוש בתא DW או TW → +10 נקודות
- **קומבו**: יצירת 2+ מילים במהלך אחד → +10 נקודות

## פקדים

- **אשר מהלך**: מאמת את המהלך, מחשב נקודות, ומעביר תור
- **אפס תור**: מחזיר את כל האותיות שהוצבו בתור הנוכחי למגש
- **החלף אותיות**: נכנס למצב החלפה - בחר עד 3 אותיות, ואז לחץ שוב על הכפתור להחלפה. החלפה מסיימת את התור
- **ערבב**: מערבב את סדר האותיות במגש (רק למראה)

## מצבי משחק

### משחק יחיד
משחק נגד עצמך - נסה לצבור כמה שיותר נקודות.

### משחק זוגי
2 שחקנים משחקים לסירוגין על אותו מחשב. כל שחקן יש לו מגש משלו.

## הרחבה והתאמה

### הוספת מילים למילון
ערוך את הקובץ `dictionary.js` והוסף מילים למערך `HEBREW_DICTIONARY`:

```javascript
const HEBREW_DICTIONARY = [
    // ... מילים קיימות
    'מילה חדשה',
    'עוד מילה'
];
```

### שינוי ערכי אותיות
ערוך את האובייקט `LETTER_VALUES` בקובץ `app.js`:

```javascript
const LETTER_VALUES = {
    'א': 1,
    'ב': 2,
    // ... וכו'
};
```

### שינוי תדירות אותיות
ערוך את האובייקט `LETTER_FREQUENCIES` בקובץ `app.js` כדי לשנות כמה פעמים כל אות מופיעה בשקית:

```javascript
const LETTER_FREQUENCIES = {
    'א': 12,  // האות א' תופיע 12 פעמים
    'ב': 8,
    // ... וכו'
};
```

### שינוי תצורת לוח
ערוך את הפונקציה `createBoard()` בקובץ `app.js` כדי לשנות את מיקומי תאי הבונוס (DL, TL, DW, TW) והכוכבים.
